Temperature–Irradiance–Spectrum Modelling for Emerging PVs

This Capstone project develops an easy‑to‑use modelling framework that improves energy yield predictions for perovskite and organic photovoltaic technologies. It adapts the widely used De Soto five‑parameter model—originally designed for silicon PVs—to accurately represent emerging materials under realistic operating conditions.

Project Motivation

Standard AM1.5 testing fails to capture real‑world behaviour, especially for emerging PV technologies. Recent research shows that perovskite and organic PVs can outperform expectations in hot, cloudy, or low‑irradiance environments.

This project extends recent work by integrating temperature coefficients, irradiance dependencies, and spectral response functions into a unified model.

Model Development

The framework incorporates:

  • Adapted De Soto five‑parameter model for perovskite & organic PVs
  • Temperature‑dependent PCE behaviour
  • Irradiance‑dependent efficiency curves
  • Spectral mismatch modelling using FARMS‑NIT
  • Angle‑of‑incidence and reflection losses

These additions allow accurate prediction of I–V characteristics under realistic environmental conditions.

Applications

The model supports:

  • Energy yield prediction
  • Levelized Cost of Energy (LCOE) analysis
  • UK grid suitability assessments
  • Techno‑economic comparison with silicon PVs

The final output is a validated modelling tool that enables consistent comparison across PV technologies.
